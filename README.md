# docAgent

docAgent 是一个结合 AI Agent 与实时协同编辑的文档应用，围绕文档创建、内容修改、资料整理和多人协作展开。用户既可以在编辑器中直接处理内容，也可以通过自然语言让 Agent 读取文档、执行修改或查询外部资料。

项目将对话、工具执行和文档管理整合在同一工作流中：用户提出需求后，Agent 根据当前上下文调用工具，将执行结果反馈给用户；文档的读取与局部编辑接入实时协同状态，便于人工编辑与 AI 操作共同参与文档处理。

## 核心功能

### AI 文档处理

提供文档创建、列表查询、内容读取、文本替换和删除等工具，支持通过对话完成具体的文档操作。用户可以要求 Agent 新建会议纪要、调整指定段落，或根据已有内容整理摘要。文档模块同时提供版本管理，便于查看历史内容。

### 多人实时协同

前端使用 TipTap 提供富文本编辑体验，通过 Yjs 和 Hocuspocus 同步多人编辑内容。Agent 的文档读取与局部替换、删除通过协同服务操作实时文档状态，使这些操作能够进入与人工编辑相同的协同流程。

### 多轮对话与记忆

会话和消息历史持久化保存，支持围绕同一任务连续提出问题、补充要求和调整结果。上下文管理会清理旧工具结果，并在达到阈值时压缩历史内容，以控制传给模型的上下文规模；原始消息仍保留在数据库中。长期记忆模块用于保存后续交互可复用的信息。

### 多步骤 Agent 执行

Agent 采用 ReAct 循环，在模型响应、工具调用和结果回传之间逐步推进任务。同一批次的工具支持并发执行，执行结果按模型声明顺序记录。任务通过消息队列异步处理，前端可查看进度，并支持任务审批、取消和续接。

### 外部信息查询

支持通过 MCP 接入网页搜索和内容抓取，将外部资料作为文档处理的补充信息来源。相关工具由统一的工具调用流程调度，具体可用能力取决于接入的 MCP 服务。

## 典型使用场景

- **文档起草与修改**：通过对话创建初稿，再结合编辑器和局部修改工具逐步完善内容。
- **资料阅读与整理**：读取已有文档，提取要点，并结合搜索到的资料辅助整理。
- **团队协作**：多人共同编辑文档，同时使用 Agent 完成内容查询和指定位置的修改。
- **连续任务处理**：在同一会话中补充要求，由 Agent 结合历史上下文继续处理。

## 整体架构

项目由 Vue 前端、Spring Boot 单体后端和独立的 Node.js 协同服务组成。前端提供对话、文档管理和编辑界面；后端负责账号、文档业务与 Agent 执行；协同服务维护实时文档状态，并通过后端完成持久化。

一次 Agent 请求从前端提交后进入 RabbitMQ 队列，由后端执行模型调用和工具调度。任务状态与步骤进度通过查询接口和 WebSocket 反馈给前端。涉及实时文档读取或局部编辑时，后端通过协同服务操作 Y.Doc；文档正文和协同状态分别保存为 Markdown 与 Yjs 二进制数据。

存储按数据用途划分：MySQL 保存业务数据、会话、消息、摘要和长期记忆；Redis 保存任务检查点、租约和异步任务状态；MinIO 保存文件、文档正文与协同状态。

## 技术栈

| 模块 | 技术 | 主要用途 |
| --- | --- | --- |
| 前端 | Vue 3、Vite、Element Plus | 对话界面、文档管理与交互 |
| 文档编辑 | TipTap、Yjs、Hocuspocus | 富文本编辑与实时协同 |
| 后端 | Java 17、Spring Boot、MyBatis-Plus | 业务接口、数据访问与 Agent 编排 |
| Agent | ReAct、工具调用、MCP | 多步骤执行与外部工具接入 |
| 关系数据 | MySQL | 账号、文档元数据、会话和记忆 |
| 任务状态 | Redis | 执行检查点、租约与任务状态 |
| 对象存储 | MinIO | 文件、Markdown 正文与协同数据 |
| 异步任务与通知 | RabbitMQ、WebSocket | 请求排队与执行进度推送 |
| 评测工具 | Python、HTTP 黑盒评测 | 文档操作、多轮对话和工具调用评测 |

## 项目组成

仓库采用 monorepo 组织，前端、后端、协同服务、接口定义、评测与部署配置各占一个顶层目录。

```text
Agent/
├─ web/                      # Vue 3 前端
│  └─ src/
│     ├─ views/              # 对话、文档管理与编辑页面
│     ├─ editor/             # 富文本编辑器
│     ├─ collaboration/      # 多人协同连接与状态
│     └─ api/                # 后端接口与进度订阅
├─ api/                      # Spring Boot 后端
│  ├─ src/main/java/com/javaee/
│  │  ├─ agentservice/       # Agent 执行、模型适配、工具、会话与记忆
│  │  ├─ documentservice/    # 文档内容、版本与访问授权
│  │  ├─ fileservice/        # 文件上传下载与对象存储
│  │  ├─ user/               # 注册、登录与用户管理
│  │  ├─ aiops/              # 指标监控、故障记录与告警
│  │  ├─ common/             # 公共模型、异常处理与工具类
│  │  └─ config/             # 安全与消息队列配置
│  ├─ src/main/resources/    # 应用配置、SQL 映射与静态资源
│  ├─ src/test/              # 后端测试
│  └─ mysql-schema.sql       # 数据库表结构
├─ collab-server/            # Node.js 实时文档同步与内容转换
├─ schemas/                  # 前后端共享的 API 定义（OpenAPI）
├─ eval/                     # 黑盒评测
│  ├─ harness/               # 评测执行、判分与报告
│  ├─ tasks/                 # 文档、多轮对话及工具任务
│  ├─ fixtures/              # 测试语料
│  └─ fixture_mcp/           # 固定网页搜索与抓取数据
├─ deploy/                   # Dockerfile 之外的部署配置：compose、Prometheus、部署脚本
├─ docs/                     # Vibe Coding 知识库
│  ├─ 01-product/            # 产品定位、功能地图、功能设计
│  ├─ 02-todos/              # 待办看板与已完成归档
│  ├─ 03-journal/            # 开发日志
│  ├─ 04-adr/                # 架构决策记录
│  └─ 05-postmortems/        # 故障与返工复盘
├─ .env.example              # 环境变量模板，复制为 .env 后填写
├─ AGENTS.md                 # AI 编程助手的项目指南
└─ CLAUDE.md                 # Claude Code 入口，引用 AGENTS.md
```
