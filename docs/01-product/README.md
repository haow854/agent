## 一句话定位

一个让 AI Agent 和人在**同一份实时文档**里协作的文档应用：人在编辑器里写，Agent 通过对话读、改、查资料，两者的修改走同一条协同通道。

## 目标用户

<!-- 待补充（T-008）：下面是根据现有功能推断的草稿，请按真实设想修改 -->

| 用户 | 典型诉求 |
| --- | --- |
| 个人写作者 | 用对话快速起草、改写、整理已有文档 |
| 小团队 | 多人同时编辑，并让 Agent 承担查资料、改指定段落等杂活 |

## 核心场景

1. **起草与修改**：对话生成初稿 → 编辑器里人工调整 → 让 Agent 局部改写某段。
2. **阅读与整理**：读取已有文档，提取要点，结合网页搜索补充资料。
3. **团队协作**：多人实时编辑，Agent 的修改与人工修改一起同步。
4. **连续任务**：在同一会话里不断补充要求，Agent 结合历史上下文继续处理。

## 设计原则

<!-- 做取舍时用来判断的准则。有新的就补上，有冲突的写 ADR。（T-008） -->

- **AI 修改走协同通道**：Agent 对文档的读写和人工编辑进入同一个 Y.Doc，而不是绕开协同直接改存储。
- **高风险操作要审批**：删除、覆盖类工具调用需要用户确认，用户可随时取消或续接任务。
- **过程可见**：Agent 的每一步工具调用都能在前端看到进度。
