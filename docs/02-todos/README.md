# 02 · 待办

| 文件 | 内容 |
| --- | --- |
| [backlog.md](backlog.md) | 看板：进行中 / 下一步 / 待排期 / 收件箱 |
| [done.md](done.md) | 已完成归档，最新的在最上面 |

## 规则

- 每条一行，带编号 `T-xxx`；关联功能写 `F-xx`，关联设计、决策、复盘写文件链接
- 下一个可用编号写在 backlog.md 顶部，用掉就加一
- 「进行中」同时不超过 3 条
- 完成后从 backlog.md 剪切到 done.md 顶部，并标上完成日期
- 收件箱定期清理：要么升级到上面的分组，要么删掉
