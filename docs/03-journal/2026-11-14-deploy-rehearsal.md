# 2026-11-14 · 本地部署演练

- **目标**：用 Docker 在本地把部署配置完整跑一遍，按 spec F-17 的验收标准逐项验证（T-006）
- **结果**：
  - 用单独的 compose 项目名 `docagent-rehearsal` 和一份临时变量文件（随机密码）运行，不影响本地开发用的容器和 `.env`
  - `build.sh` 打包后 `up -d --build`：7 个服务全部启动，后端约 7 秒就绪；只有 web 发布了 80 端口
  - 逐项验证（全部经 nginx 访问 `http://localhost`）：
    - 前端首页、`/editor/...` 深层链接正常；`/api-docs`、`/swagger-ui.html`、`/actuator/health`、`/ai/read` 都落到前端页面，不对外
    - 注册演示账号、登录正常；关闭注册后注册接口返回 403
    - 两个标签页打开同一篇文档，输入实时同步，显示对方光标
    - Agent 抓取网页（镜像里的 mcp-server-fetch）并修改文档，改动写回存储；文档助手的修改实时出现在另一个标签页；后端统计到经 nginx 建立的 STOMP WebSocket 会话
    - 上传 5 MB 的文件正常（nginx 上限 100 MB）
    - 容器里 Tesseract 用命令行识别中英文图片正常
    - 协同服务进程被杀后自动重启
  - 内存：7 个容器合计约 1.2 GB（api 约 770 MB）；镜像 api 937 MB、collab-server 286 MB、web 77 MB
  - 打包时 `clean` 清掉了 `api/target`，本地 IntelliJ 里运行的后端不受影响
- **问题**：
  - 后端经 tess4j 调用 OCR 的路径没有入口可以触发（T-020），只验证了命令行
  - Docker 守护进程重启后的自动恢复没有实际测，只测了单个容器崩溃后的重启
- **遗留**：
  - 上公网前先修 T-001（进度推送不校验登录、全局广播），再提交代码
  - T-005：服务器初始化（公钥、防火墙、Docker 和镜像加速、`.env`），然后一键部署并在公网验收
