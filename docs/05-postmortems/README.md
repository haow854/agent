# 05 · 复盘

出了问题之后写，用 [_template.md](_template.md)，文件名 `YYYY-MM-DD-<slug>.md`。

## 什么时候写

- 部署或线上出了故障
- bug 花了超过一次会话才定位
- AI 的改动把别的地方改坏了，或者方向错了导致返工

## 怎么写

- **对事不对人**，也不怪 AI：问的是「流程里缺了什么，才让这件事发生」
- 根因问到底：至少追问一次「为什么当时没发现」
- **每篇至少一条行动项**，要么是待办（`T-xxx`），要么是写进 `AGENTS.md` 的约定。没有行动项的复盘等于没写
- 写完不再修改；后续发现补充信息时在文末追加
