# YYYY-MM-DD · 一句话描述发生了什么

- **严重程度**：高（服务不可用 / 数据丢失）/ 中（功能异常）/ 低（返工、耽误进度）
- **关联**：F-xx、T-xxx、ADR-xxxx、日志 03-journal/xxx.md

## 摘要

两三句话：什么坏了、影响了什么、现在好了没有。

## 时间线

| 时间 | 事件 |
| --- | --- |
| HH:MM | 做了什么改动 / 发现了什么现象 |
| HH:MM | 如何定位 |
| HH:MM | 如何恢复 |

## 根因

直接原因是什么？再往下问：为什么会有这个原因？

## 为什么没有更早发现

缺了哪个测试、哪项检查、哪条约定？如果是 AI 改出来的，它当时缺了什么上下文？

## 修复

做了什么让它恢复，改了哪些地方。
