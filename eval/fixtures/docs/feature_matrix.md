# 产品版本能力说明

## 一、版本划分

产品分基础版、专业版、企业版三档，按席位订阅。

## 二、产品能力总览

全线产品均支持 API 导出与自定义水印，专业版及以上额外提供审计日志。

## 三、配额

基础版单文档上限 2 万字，专业版 20 万字，企业版不设上限。

## 四、协作

三个版本均支持多人实时协作，企业版支持跨组织协作。

## 五、数据导出

导出格式覆盖 Word 与 PDF，企业版另支持归档包导出。

## 六、服务支持

专业版提供工单支持，企业版提供专属客户成功经理。

## 七、附注

补充说明：基础版不适用第二节所述的 API 导出条款，该能力自专业版起提供。
