# 二季度增长报告

## 一、整体表现

二季度用户增长延续了一季度的势头，注册转化率环比提升两个百分点。渠道结构保持稳定，自然流量占比过半。本报告数据来源于内部埋点平台。

## 二、分渠道分析

搜索渠道贡献了最大的用户增长，内容渠道次之。付费投放在月中有一次预算上调，带来一波短期用户增长，但留存表现弱于自然渠道，后续将收紧投放口径。

## 三、重点城市

新一线城市的用户增长速度显著高于一线城市，其中成都与杭州连续两个月排在前两位。区域运营团队计划在三季度对这两个城市追加本地化活动。

## 四、下季度展望

三季度的用户增长目标定为环比百分之十五，重点押注内容渠道的复制与新城市的冷启动。目标拆解将在季度经营会上逐条对齐。
