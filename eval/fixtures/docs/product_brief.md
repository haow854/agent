# DocFlow 产品介绍

DocFlow 是一款面向中小团队的在线文档协作平台，定位是把写作、评审与归档收进同一条工作流。产品于两年前上线，目前服务约六千个团队，付费转化率在同类产品中处于中游偏上水平。

平台早期从技术团队的接口文档场景切入，随后逐步扩展到市场文案、运营周报与法务合同评审。用户调研显示，团队选择 DocFlow 的前三个理由是版本追溯清晰、评论定位精确、导出格式稳定。

当前版本的核心能力包括：多人实时协作编辑，段落级评论与建议模式，文档全生命周期的版本管理，细粒度的分享权限，以及覆盖 Word 与 PDF 的高保真导出。移动端提供只读与轻量批注，深度编辑仍以桌面端为主。

商业化方面采用席位订阅制，基础版免费，专业版按席位年付。近两个季度的收入增长主要来自五十人以上团队的整单采购，销售团队据此调整了打单策略，把重心从个人转向部门决策人。

未来两个季度的规划围绕三件事展开：离线编辑能力补齐移动场景的短板，模板市场沉淀行业最佳实践，以及开放 API 让文档流入客户已有的审批与项目管理系统。团队规模保持在四十人以内，优先保证迭代质量而非功能数量。
