# 新版工作台项目日志

本页按时间记录新版工作台项目的关键节点，供季度复盘使用，日常琐事不入此页。

2026-01-12，立项评审通过，确定以「统一入口、可组装卡片」为核心设计方向，预算与人力当场敲定。

一月下旬完成竞品走查，输出对比结论若干，此处不展开。

2026-02-09，需求冻结，砍掉了首页信息流与第三方日历两项争议需求，冻结后仅接受缺陷级变更。

2026-03-05，架构设计定稿，前端确定采用微前端拆分，网关层新增卡片配置服务，评审记录归档在架构组空间。

三月中旬起进入密集开发期，期间两次周会调整了排期颗粒度。

2026-04-18，首个内测版本发布，面向内部五十人灰度，首周收集反馈一百二十条，高频问题集中在加载速度。

2026-05-30，公测上线，开放全量老用户自主切换，切换率第一周达到百分之三十七。

2026-06-21，迎来第 10 万名使用新版工作台的用户，运营侧同步启动了老版本下线倒计时公告。

2026-07-15，正式版发布，老版本入口关闭，项目转入常规迭代，本日志停止更新。
